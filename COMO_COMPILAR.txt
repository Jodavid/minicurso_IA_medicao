COMO COMPILAR O LIVRO E OS SLIDES (HTML e PDF)
==============================================

Todos os comandos abaixo são para rodar no R (console ou RStudio), a partir
da pasta raiz do projeto (minicurso_IA_medicao_publico/).

Requisitos: pacotes bookdown, rmarkdown, knitr, readr, dplyr, stringr, withr;
            Quarto instalado; uma distribuição LaTeX com xelatex (ex.: TinyTeX);
            Google Chrome/Chromium (para o PDF dos slides).

Se o R reclamar "pandoc version 1.12.3 or higher is required", aponte para o
pandoc que vem com o Quarto (rode antes de compilar):

  Sys.setenv(RSTUDIO_PANDOC = "/opt/quarto/bin/tools/x86_64")


----------------------------------------------------------------------
1) LIVRO (pasta livro/) - a saída vai para docs/
----------------------------------------------------------------------

# --- Livro em HTML (gitbook) -> docs/index.html ---
setwd("livro")
bookdown::render_book("index.Rmd", output_format = "bookdown::gitbook")
setwd("..")

# --- Livro em HTML + slides + .zip do material (script completo do projeto) ---
setwd("livro")
source("build.R")
setwd("..")

# --- Livro em PDF -> docs/ia-instrumento-medicao.pdf ---
setwd("livro")
bookdown::render_book("index.Rmd", output_format = "bookdown::pdf_book")
setwd("..")

# --- Os dois de uma vez (HTML e PDF) ---
setwd("livro")
bookdown::render_book("index.Rmd", output_format = "all")
setwd("..")

Obs.: compilar o PDF NÃO apaga o HTML (e vice-versa); os dois ficam em docs/.
As opções do PDF (xelatex, natbib, sumário) estão em livro/_output.yml.


----------------------------------------------------------------------
2) SLIDES (pasta slides/)
----------------------------------------------------------------------

# --- Slides em HTML (reveal.js) -> slides/<deck>.html ---
# (alternativa, com o pacote quarto do R: quarto::quarto_render("slides/<deck>.qmd"))
#   slides/parte1_conceitos.qmd  formato A, Parte 1: conceitos, sem resultados (~55 slides, 2h)
#   slides/completo_R.qmd        formato B: minicurso inteiro com código R e saídas (~170 slides, 4h)
#                                (inclui os blocos de slides/partes_R/; o código roda a partir da raiz)
#   slides/completo_python.qmd   formato B com código Python, espelho do completo_R slide a slide
#                                (inclui os blocos de slides/partes_python/; usa o kernel python3)
for (d in c("parte1_conceitos", "completo_R", "completo_python"))
  system(paste0("quarto render slides/", d, ".qmd"))
# Para o PDF de cada deck, troque "parte1_conceitos" pelo nome do deck no bloco abaixo.
# O build.R do livro copia para docs/slides/ todos os decks compilados (HTML e PDF).

# --- Slides em PDF -> slides/<deck>.pdf ---
# Imprime o HTML pelo Chrome em modo "print-pdf" do reveal.js
# (compile o HTML antes; troque "google-chrome" por "chromium" se for o caso).
html <- normalizePath("slides/parte1_conceitos.html")
pdf  <- sub("\\.html$", ".pdf", html)
system2("google-chrome", c(
  "--headless=new", "--disable-gpu", "--no-pdf-header-footer",
  "--virtual-time-budget=20000",
  shQuote(paste0("--print-to-pdf=", pdf)),
  shQuote(paste0("file://", html, "?print-pdf"))
))

# (alternativa, com o pacote pagedown:)
# install.packages("pagedown")
# pagedown::chrome_print(paste0("file://", html, "?print-pdf"), output = pdf)

# Copiar o PDF dos slides para o site (opcional):
file.copy(pdf, file.path("docs/slides", basename(pdf)), overwrite = TRUE)
