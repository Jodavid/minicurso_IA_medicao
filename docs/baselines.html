Inteligência Artificial como Instrumento de Medição

Capítulo 4 Baselines: quanto se acerta sem LLM?

Antes de usar um LLM, precisamos saber quanto se acerta sem ele. Um LLM só “vale a pena” se superar instrumentos mais baratos e mais transparentes de forma estatisticamente consistente, e isso é uma afirmação a ser testada, não uma impressão.

4.1 Dicionário

O primeiro baseline é um dicionário: um conjunto de expressões regulares que traduzem o livro de códigos em regras explícitas. É barato, transparente e totalmente auditável.

classifica_dicionario <- function(ementa) {
  x <- str_to_lower(ementa)
  case_when(
    str_detect(x, REGEX$punir) & str_detect(x, REGEX$ia) ~ "PUNIR",
    !str_detect(x, REGEX$ia)                               ~ "OUTRO",
    str_detect(x, REGEX$promover)                          ~ "PROMOVER",
    TRUE                                                   ~ "REGULAR"
  ) |> factor(levels = CATEGORIAS)
}

As expressões REGEX$punir, REGEX$ia e REGEX$promover estão em R/funcoes_medicao.R. A ordem das regras implementa a precedência do livro de códigos.

4.2 TF-IDF e regressão logística

O segundo baseline é um modelo de aprendizado supervisionado clássico: as ementas viram vetores TF-IDF (após remover pontuação, números e stopwords e aplicar stemming), e uma regressão logística multinomial com penalização elastic-net (glmnet) é ajustada. Como a amostra-ouro é pequena, o desempenho é estimado por validação cruzada com 10 dobras: cada ementa é classificada por um modelo que não a viu no treino.

4.3 Resultados

Tabela 4.1: Desempenho dos baselines na amostra-ouro (n = 120).
Método Acurácia F1 macro Kappa
Dicionário (regex) 81% 0,78 0,70
TF-IDF + logística (CV 10) 68% 0,50 0,41
Classe majoritária (REGULAR) 57% 0,18 0,00

A linha classe majoritária é o piso: chutar sempre REGULAR acerta 57% das ementas, mas tem kappa zero, porque não acerta nada além do que o acaso já acertaria. É por isso que a acurácia sozinha engana quando as classes são desbalanceadas.

O dicionário “viu a prova” As regras do dicionário foram escritas depois de ler as ementas do corpus. Seu desempenho aqui (kappa 0,70) é, portanto, otimista: é um caso clássico de data leakage. Num estudo real, as regras seriam definidas antes, ou validadas em dados novos (por exemplo, proposições apresentadas depois da data de coleta).

4.4 O “mesmo” método, implementações diferentes

As trilhas em R e Python do minicurso produzem os mesmos números em todas as análises (a menos de diferenças de até 0,01 nos resultados que dependem de sorteios), com uma exceção instrutiva: o baseline TF-IDF. Em R, com glmnet (elastic-net e stemming), o kappa é 0,41; em Python, com scikit-learn (penalização L2, sem stemming), é 0,51. “TF-IDF + logística” não é um método, é uma família de escolhas, e cada escolha precisa ser relatada.

4.5.4 TF-IDF e regressão logística com validação cruzada

Este é o bloco mais demorado do capítulo (alguns segundos em R): são 10 ajustes do modelo, cada um com sua própria validação cruzada interna para escolher a penalização.

library(tm); library(glmnet)
prepara_dtm <- function(textos) {
  vc <- VCorpus(VectorSource(str_to_lower(textos)))
  vc <- tm_map(vc, removePunctuation)
  vc <- tm_map(vc, removeNumbers)
  vc <- tm_map(vc, removeWords, stopwords("portuguese"))
  vc <- tm_map(vc, stemDocument, language = "portuguese")
  vc <- tm_map(vc, stripWhitespace)
  DocumentTermMatrix(vc, control = list(weighting = weightTfIdf,
                                        bounds = list(global = c(2, Inf))))
}
X <- as.matrix(prepara_dtm(ouro$ementa))

modelo = make_pipeline(
    TfidfVectorizer(lowercase=True, stop_words=STOPWORDS_PT, min_df=2,

O que está sendo executado. Primeiro, cada ementa vira um vetor: uma coluna por termo que aparece em pelo menos duas ementas, com peso TF-IDF (frequência do termo na ementa, descontada pela frequência do termo no corpus). Em R, antes disso, removemos pontuação, números e stopwords e reduzimos as palavras ao radical (stemming: “criminaliza” e “criminalização” viram o mesmo termo); em Python, só removemos as stopwords. Depois, as 120 ementas são divididas em 10 dobras. Para cada dobra, o modelo é treinado nas outras nove e prevê a dobra deixada de fora; assim, toda previsão é feita por um modelo que não viu aquela ementa. Repare nos termos de maior peso total: são palavras da redação legislativa (“lei”, “uso”, “dispõe”, “sobre”), que nada dizem sobre punir, regular ou promover. Com 120 exemplos, sobra pouca informação para o modelo aprender a fronteira entre as categorias. Repare também que o R encontra 303 termos e o Python, 313: o stemming junta palavras que o Python mantém separadas.
