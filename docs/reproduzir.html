Inteligência Artificial como Instrumento de Medição

Apêndice D Como reproduzir

D.1 Sem LLM e sem internet (como em sala)

Tudo parte dos dados e do cache congelados. Em R:

source("R/00_pacotes.R")   # instala as dependências (uma vez)
targets::tar_make()        # refaz amostra-ouro, baselines, validação, inferência e figuras

ou, passo a passo: Rscript R/02_amostra_ouro.R, R/03_baselines.R, R/05_validacao.R, R/06_inferencia.R.

Em Python: abra os notebooks de python/ (no Jupyter ou no Google Colab) na ordem 01 a 05. A primeira célula de cada um configura o ambiente; as dependências estão em requirements.txt. A instalação de tudo, passo a passo, está no Apêndice A.

D.2 Refazendo a coleta e a anotação

Rscript R/01_coleta.R                # ~5 a 10 min, APIs públicas (gera um corpus novo!)
ollama pull hf.co/maritaca-ai/S5-nano-GGUF:Q4_K_M         # S5-nano em 4 bits (~3,5 GB)
ollama create s5-nano-instruct -f modelos/Modelfile.s5-nano-instruct
python python/anotar_llm.py --todas  # ~15 min numa GPU de notebook; retoma de onde parou

D.3 Este livro e os slides

setwd("livro")
source("build.R")                      # compila o livro em ../docs/
quarto render slides/parte1_conceitos.qmd   # Parte 1: conceitos (formato A, 2 h)
quarto render slides/completo_R.qmd         # minicurso completo com código R (formato B, 4 h)
quarto render slides/completo_python.qmd    # minicurso completo com código Python (formato B, 4 h)
